## 数据集说明

本项目使用 **Free Spoken Digit Dataset (FSDD)**，文件命名格式：

```
{digit}_{speaker}_{index}.wav
```

例如：`0_george_0.wav`、`5_jackson_23.wav`

## 方法说明

### 一、特征提取 (共同部分)

| 特征 | 说明 |
|------|------|
| MFCC | 13维梅尔频率倒谱系数 |
| Δ MFCC | 一阶差分（速度特征） |
| ΔΔ MFCC | 二阶差分（加速度特征） |
| **合计** | **39维特征向量** |

- 采样率：16000 Hz
- 帧长：25ms（400点），帧移：10ms（160点）
- 预加重系数：0.97

---

### 二、VQ（矢量量化）方法

**原理：**

```
训练阶段：
  对每个数字类别 d ∈ {0,...,9}：
      收集所有训练帧 → K-Means 聚类 → 码本 Cd（K=32个码字）

识别阶段：
  输入语音 → 提取MFCC序列 {x₁,...,xT}
  对每个类别 d 计算平均量化失真：
      dist(d) = (1/T) Σₜ min_k ||xₜ - cd,k||²
  预测标签 = argmin_d dist(d)
```

**超参数：** 码本大小 K=32

---

### 三、HMM-GMM 方法

**原理：**

```
训练阶段（Baum-Welch / EM 算法）：
  对每个数字类别 d 训练 GMMHMM：
      - 状态数 N=5（对应不同音素阶段）
      - 每状态 GMM 混合数 M=3
      - 从左到右（Bakis）拓扑
      - 迭代次数上限：80次

识别阶段（Viterbi 解码）：
  输入语音 → 提取MFCC序列 {x₁,...,xT}
  对每个类别 d 计算对数似然：
      score(d) = log P(X | λd)
  预测标签 = argmax_d score(d)
```

**超参数：** 状态数 N=5，GMM 混合数 M=3

## 优缺点分析

### VQ（矢量量化）

**✅ 优点：**
1. **原理简单**：K-Means 聚类，易于实现和理解
2. **推理极快**：只需计算帧到码字的欧式距离，单句 < 20ms
3. **资源占用少**：模型仅存储 K×D 维码书，适合嵌入式部署
4. **超参数少**：只需调节码本大小 K，调参简单
5. **训练稳定**：K-Means 收敛有理论保证

**❌ 缺点：**
1. **忽略时序信息**：将帧独立处理，丢失语音的时序动态
2. **对语速不鲁棒**：无法处理语速变化引起的帧数变化
3. **噪声敏感**：低 SNR 下准确率急剧下降
4. **说话人适应差**：不同说话人的声学空间可能差异较大
5. **理论上限低**：无法建模音素状态转移，天花板较低

---

### HMM-GMM

**✅ 优点：**
1. **时序建模**：HMM 天然建模语音的状态转移动态
2. **语速不变性**：Viterbi 解码内含 DTW，自动对齐不同语速
3. **声学建模精确**：GMM 可拟合复杂的多峰特征分布
4. **准确率高**：传统 ASR 的主流基线，通常比 VQ 高 10-20%
5. **相对鲁棒**：噪声下性能下降更平缓

**❌ 缺点：**
1. **训练复杂**：EM 算法需多次迭代，训练耗时是 VQ 的 5-20 倍
2. **超参数多**：状态数、混合数、拓扑结构都需调节
3. **推理较慢**：Viterbi 解码复杂度 O(N²T)，实时性稍差
4. **数据需求**：小样本时过拟合风险，需要足够训练数据
5. **实现复杂**：概率模型初始化、数值稳定性等问题需仔细处理

---

## 总结对比

| 维度 | VQ | HMM-GMM | 推荐场景 |
|------|----|---------|----------|
| 识别精度 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 高精度 → HMM-GMM |
| 推理速度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 实时嵌入式 → VQ |
| 噪声鲁棒性 | ⭐⭐ | ⭐⭐⭐⭐ | 噪声环境 → HMM-GMM |
| 实现难度 | ⭐（简单） | ⭐⭐⭐⭐ | 快速原型 → VQ |
| 资源占用 | ⭐（少） | ⭐⭐⭐ | 低资源 → VQ |
| 可扩展性 | ⭐⭐ | ⭐⭐⭐⭐⭐ | 系统扩展 → HMM-GMM |

> **结论：** VQ 适合快速验证和资源受限场景；HMM-GMM 是传统语音识别的工业基线，精度和鲁棒性全面优于 VQ，代价是更高的计算复杂度。
